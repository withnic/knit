**knit** は、[google/wire](https://github.com/google/wire)（アーカイブ済み）と同じスタイルで使える、Go 向けの軽量なコンパイル時 DI（依存性注入）コードジェネレータです。

コンストラクタを列挙するだけで、knit が呼び出し順を解決し、クリーンアップ関数やエラー処理まで含めた読みやすい普通の Go コードを生成します。リフレクションも実行時コンテナも使いません。

- **knit モード（デフォルト）**: `knit.Build` / `knit.NewSet` / `knit.Bind` で宣言します。google/wire への依存は不要です。
- **wire モード（`-mode=wire`）**: `wire` コマンドのドロップイン代替です。既存の `wire.go` をそのまま読み、同じ `wire_gen.go` を生成します。
- **依存グラフ**: 実行のたびに `.knit/di-graph.json` も出力します。各 Injector が何に依存しているかを機械可読な形で記録したもので、テスト影響範囲解析などのツールで使えます。

## インストール

Go 1.26 以上が必要です。

```sh
# コマンドラインツール
go install github.com/withnic/knit/cmd/knit@latest

# またはモジュールのツール依存として固定し、`go tool knit` で実行
go get -tool github.com/withnic/knit/cmd/knit@latest

# Injector の宣言で使うマーカーパッケージ（knit モード）
go get github.com/withnic/knit@latest
```

Linux・macOS・Windows 向けのビルド済みバイナリは [GitHub Releases](https://github.com/withnic/knit/releases) にあります。

## クイックスタート

**1. 普通のコンストラクタ（プロバイダ）を書きます。**

```go
package app

type Store interface{ Get() string }

type SQLStore struct{ /* ... */ }

func (s *SQLStore) Get() string { /* ... */ }

func NewDSN(ctx context.Context) DSN { /* ... */ }

// プロバイダはクリーンアップ関数やエラーを返せます。
func NewSQLStore(dsn DSN) (*SQLStore, func(), error) { /* ... */ }

func NewServer(s Store) *Server { /* ... */ }
```

**2. Injector を宣言します。** `knitinject` ビルドタグ付きのファイル（例: `knit.go`）に書きます。本体は、使ってよいものを列挙した `knit.Build` 呼び出し 1 つだけです。

```go
//go:build knitinject

package app

import (
	"context"

	"github.com/withnic/knit"
)

var StoreSet = knit.NewSet(NewDSN, NewSQLStore, knit.Bind(new(Store), new(*SQLStore)))

func InitializeServer(ctx context.Context) (*Server, func(), error) {
	panic(knit.Build(StoreSet, NewServer))
}
```

**3. 生成します。**

```sh
knit gen ./...
```

宣言の隣に `knit_gen.go` が生成されます。

```go
// Code generated by knit. DO NOT EDIT.

//go:build !knitinject

package app

import (
	"context"
)

// Injectors from knit.go:

func InitializeServer(ctx context.Context) (*Server, func(), error) {
	var cleanups []func()
	cleanup := func() {
		for i := len(cleanups) - 1; i >= 0; i-- {
			cleanups[i]()
		}
	}
	v1 := NewDSN(ctx)
	v2, cleanupV2, err := NewSQLStore(v1)
	if err != nil {
		return nil, nil, err
	}
	cleanups = append(cleanups, cleanupV2)
	v3 := NewServer(v2)
	return v3, cleanup, nil
}
```

**4. 普通の関数として使います。**

```go
srv, cleanup, err := app.InitializeServer(ctx)
if err != nil {
	return err
}
defer cleanup()
```

ヒント: モジュール内のファイルに `//go:generate go tool knit gen` を書いておけば、`go generate ./...` で再生成できます。

## 基本概念

| 宣言 | 意味 |
|---|---|
| プロバイダ | `(T)`、`(T, error)`、`(T, func())`、`(T, func(), error)` のいずれかを返すトップレベル関数。引数がその依存です。 |
| `knit.Build(...)` | それを含む関数を Injector にします。引数が入力、第 1 戻り値が構築する値で、`func()` や `error` も返せます。 |
| `knit.NewSet(...)` | プロバイダ・他のセット・Bind をまとめた、再利用できるパッケージ変数を作ります。ネストでき、別パッケージに置くこともできます。 |
| `knit.Bind(new(Iface), new(*Impl))` | インターフェースの要求を、いずれかのプロバイダが作る具象型で満たします。 |

プロバイダが失敗した場合は、それまでに作ったもののクリーンアップ関数を逆順（LIFO）に実行してからエラーを返します。

生成コードは決定論的で、同じ入力からは常にバイト単位で同じ出力になります。エラーには依存のつながりがすべて表示されます。

```
failed to resolve provider for injector 'InitializeUserService':
  service.UserService -> repo.UserRepository -> *db.Pool (provider not found)
```

## モード

2 つのモードの違いは、マーカーパッケージ・ビルドタグ・出力ファイル名だけです。各モードはもう一方の宣言を無視します。

| | knit（デフォルト） | wire（`-mode=wire`） |
|---|---|---|
| マーカーパッケージ | `github.com/withnic/knit` | `github.com/google/wire` |
| 宣言 | `knit.Build` / `knit.NewSet` / `knit.Bind` | `wire.Build` / `wire.NewSet` / `wire.Bind` |
| Injector ファイルのタグ | `//go:build knitinject` | `//go:build wireinject` |
| 生成ファイル | `knit_gen.go` | `wire_gen.go` |

## google/wire からの移行

**コードはそのままにする場合**: これまで `wire` を実行していたところで `knit gen -mode=wire ./...` を実行します。出力は通常の `wire_gen.go` です。

**knit モードに切り替える場合**:

1. Injector ファイルのビルドタグを `wireinject` から `knitinject` に変えます。
2. import の `github.com/google/wire` を `github.com/withnic/knit` に、`wire.` を `knit.` に置き換えます。
3. 古い `wire_gen.go` を削除してから `knit gen ./...` を実行します。
4. `go mod tidy` で google/wire を外します。

### サポートしない機能

knit は wire の機能のうち、意図的に小さなサブセットだけをサポートします。以下は代わりの書き方を示すエラーになります。

| wire の機能 | 代わりの書き方 |
|---|---|
| `wire.Struct` | 明示的な `NewXxx` コンストラクタ |
| `wire.Value`、`wire.InterfaceValue` | 1 行の `ProvideXxx` 関数 |
| `wire.FieldsOf` | 1 行の Getter 関数 |
| 可変長引数（`...T`） | 明示的なスライス型（`[]T`）か専用のプロバイダ |
| メソッドやジェネリックのプロバイダ・Injector | 通常のトップレベル関数 |

## コマンドリファレンス

```
knit gen [flags] [packages...]   コードと .knit/di-graph.json を生成（パッケージ省略時は ./...）
knit version                     バージョンを表示
```

| フラグ | デフォルト | 説明 |
|---|---|---|
| `-mode` | `knit` | `knit` または `wire` |
| `-out` | `knit_gen.go` / `wire_gen.go` | 各パッケージディレクトリに生成するファイル名 |
| `-graph-out` | `.knit/di-graph.json` | 依存グラフの出力先。空文字で出力しない |
| `-dry-run` | `false` | ファイルを書かずに生成コードを表示 |

終了コード: `0` 成功、`1` 解析・生成エラー、`2` 使い方の誤り。

内容が変わらないファイルは書き換えません。`di-graph.json` の形式は [docs/02_data_models.md](docs/02_data_models.md) を参照してください。
